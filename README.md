# Overlio Live Scoreboard

Live scoreboard application for sports events with real-time updates and admin panel.

## Features

- 🏟️ Live scoreboard with real-time updates
- 👤 User authentication with case-insensitive username
- 🎮 Admin panel for score management
- 👑 Superadmin panel for tenant management
- 💳 Payment integration
- 📱 Responsive design for all devices
- 🔒 Secure authentication with rate limiting

## Installation

```bash
npm install
npm start
```

## Usage

- **Homepage**: http://localhost:3000/
- **Admin Panel**: http://localhost:3000/admin
- **Super Admin**: http://localhost:3000/superadmin

## Tech Stack

- Node.js + Express
- Socket.IO for real-time updates
- HTML5 + CSS3 + JavaScript
- bcrypt for password hashing
